# Form Builder App — UI Design

A self-contained, clickable mobile UI design for the **Form Builder** field data-collection app
(a conservation/field-survey form builder). It's a single HTML file — no build step, no dependencies —
with a phone frame, a device picker, and every screen wired up as a clickable prototype.

## Live preview

👉 **https://ravi26design.github.io/Form-Builder-App-UI-Design/**

## What's inside

The design covers the full **Field User** experience:

- **Home** — stat cards + "Your Forms"
- **Forms** — form cards with New Submission + bookmark
- **New Submission** — step-by-step wizard with follow-up questions and a **repeatable section** (Household Members)
- **Records** — records list, record detail, and the fully rendered submitted answers
- **Offline Sync** — Waiting-to-sync / Drafts tabs
- **Profile** — account settings, change password, 2FA, notifications, language, help & support, legal

Brand: green `#19643E` + amber `#EC990C`.

## Run locally

Just open `index.html` (or `mobile-app.html`) in any browser.
